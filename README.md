Tampermonkey userscript that adds "Not interested" and "Don't recommend channel" buttons over YouTube video thumbnails. It supports Russian and English YouTube interfaces and invokes YouTube's existing feedback menu actions.

Install [Tampermonkey](https://www.tampermonkey.net/), open the [userscript](https://raw.githubusercontent.com/sashokey/youtube-quick-feedback/master/youtube-quick-feedback.user.js), and confirm installation. Reload YouTube.

Hover over a video thumbnail and click the desired feedback button. The action must be available in that video's YouTube menu.
